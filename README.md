# バドミントン大会運営

ブラウザで動くバドミントン大会の運営ソフトです。インストール不要で、パソコン・タブレットのブラウザ（Chrome / Edge / Safari）で使えます。
シングルス・ダブルス・団体戦に対応しています。

## できること

| 画面 | 内容 |
| --- | --- |
| 大会設定 | 大会名・日付・会場・コート数・休憩時間、種目の追加（トーナメント／リーグ／予選リーグ＋決勝トーナメント、点数・ゲーム数、3位決定戦、団体戦のオーダー、参加費）、バックアップ |
| 参加者 | エントリー入力、CSV・Excel貼り付けでの取込（Shift_JIS／UTF-8）、選手一覧、重複チェック（同じ種目への二重登録・出場種目数の上限・同姓同名）、所属別の参加数・参加費と受領管理 |
| 組み合わせ | シードと同じ所属の分散を考えた自動配置、BYE（不戦勝）の自動配置、枠のクリックで入れ替え、同じ所属どうしが当たる回戦の確認、リーグのグループ分け、予選リーグ上位から決勝トーナメント作成、試合番号の自動採番 |
| 進行 | コートの状況表示、空きコートに入れる試合の提案（出場中・休憩不足の選手を避ける）、コール（音声読み上げ）、開始・結果入力、勝者の自動勝ち上がり、棄権・不戦勝、終了見込み時刻 |
| 結果 | トーナメント表（勝ち上がり線を赤で表示）、リーグ星取表と順位、入賞者、選手ごとの戦歴、試合一覧（CSV出力）、試合時間の分析 |
| 放送 | コール文のひな形（{コート} {番号} {A} {B} などを差し込み）、声と速さの設定、ふりがなでの読み上げ、自由放送 |
| 印刷 | 対戦表、進行表、タイムテーブル（コート別の見込み）、審判用紙（個人戦・団体戦）、放送原稿、大会結果報告、参加者名簿、参加費一覧、看板（名前札）、賞状（縦書き・横書き） |

## 使い方の流れ

1. **大会設定**で大会情報と種目を登録する（「サンプル大会を読み込む」で動きを試せます）
2. **参加者**でエントリーを入力または取り込み、シードを付ける。「重複チェック」で不備を確認
3. **組み合わせ**で「自動配置」（リーグは「グループ分け・リーグ作成」）。必要なら枠を入れ替える
4. **印刷**で対戦表・進行表・審判用紙などを印刷する
5. 当日は**進行**で空いたコートに試合をコールし、結果を入力する。勝者は自動で次の試合に入ります
6. **結果**と**印刷**で入賞者一覧・賞状を出す

データはブラウザ内に自動保存されます。別のパソコンへ移すときや控えには、大会設定の「バックアップを保存／読み込む」を使ってください。
操作を間違えたときは、画面右上の ↶（Ctrl+Z）で元に戻せます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run build    # dist/ に公開用ファイルを作成
```

`main` ブランチに push すると、GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください）。

### 構成

- `src/logic/` … 組み合わせ（`draw.ts`）、勝ち上がり（`bracket.ts`）、リーグ順位（`league.ts`）、スコア判定（`score.ts`）、団体戦（`team.ts`）、進行予定（`scheduler.ts`）など。画面に依存しない処理で、テストは `logic.test.ts`
- `src/actions.ts` … 画面から呼ぶ操作（組み合わせ作成、コール、結果保存など）
- `src/store.ts` … データの保存と元に戻す／やり直し
- `src/pages/` … 各画面、`src/components/` … トーナメント表・スコア入力など
